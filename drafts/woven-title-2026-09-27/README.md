# 태피스토리 직조 타이틀 초안 — 보류

2026-09-27 작업 종료 시점의 초안을 `resume.patch`에 보관했습니다. 메인 화면은 기존 SVG 타이틀로 복원했으며, 스크롤 잠금은 적용하지 않았습니다.

## 보관 내용

- `MainSection.tsx`: 직조 타이틀 연결, 배경과 서브 텍스트 배치
- `WovenTitle.tsx`: Canvas 직조 렌더링, 실 단위 튕김, 키보드 지원, 모션 감소 설정 대응
- `weaveMotion.ts`: 첫 두 번의 씨실 왕복을 보여준 뒤 가속하여 3초 안에 완성하는 타이밍
- `globals.css`: 초안의 관련 스타일 변경
- `check-woven-title-motion.mjs`: 직조 타이밍 검사

실사 표현 없이 보라색 경사와 씨실이 제목의 획을 만드는 방향입니다. 마지막 초안은 반짝이는 교차 셀 대신 이어진 무광 실을 사용하며, 씨실이 통과한 뒤 눌려 쌓이도록 변경했습니다. 주변 실은 서브 텍스트 아래까지 이어지고, 폭 전체의 대비가 점차 낮아집니다.

보류 이유는 설명 없이 직조로 인식되는지, 인위적으로 생성된 느낌이 줄었는지 추가 검토가 필요하기 때문입니다.

## 재개 방법

저장소 루트에서 실행합니다. 이후 관련 파일을 수정했다면 먼저 패치 적용 가능 여부를 확인하세요. 검사가 실패하면 변경 내용을 비교하여 필요한 부분만 복원합니다.

```sh
git apply --check drafts/woven-title-2026-09-27/resume.patch
git apply drafts/woven-title-2026-09-27/resume.patch
pnpm type-check
node scripts/check-woven-title-motion.mjs
```

별도 라이브러리 설치나 설정 변경은 필요하지 않습니다. 보관 당시 패치의 역방향 검사와 복원 가능 여부를 모두 확인했습니다. 다른 작업의 변경 사항은 패치에 포함하지 않았습니다.
